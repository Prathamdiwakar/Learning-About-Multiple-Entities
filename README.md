# Learning About Multiple Entities

🚀 **Learning About Multiple Entities** is a Java + Spring Boot based learning project focused on understanding **JPA/Hibernate entity relationships** in a clear and practical way.

This repository is created for **hands-on practice** of mapping multiple entities and understanding how data flows between them using Spring Boot and JPA.

---

## 📌 What You’ll Learn

* 🔹 Entity relationships in JPA

  * One-to-One
  * One-to-Many
  * Many-to-One
  * Many-to-Many
* 🔹 Fetch Types

  * Lazy Fetch
  * Eager Fetch
* 🔹 Entity Mapping Annotations

  * `@Entity`
  * `@Id`
  * `@OneToOne`
  * `@OneToMany`
  * `@ManyToOne`
  * `@JoinColumn`
* 🔹 How entities interact in real-world backend applications
